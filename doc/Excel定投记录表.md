
# Excel定投记录表
> 使用方法：复制全部表格文本，粘贴到Excel A1单元格，自动分列；公式我标注清楚，你直接输入即可

|日期|定投标的类型|标的名称|当月投入金额(元)|累计总投入(元)|当前市值(元)|持仓盈亏(元)|盈亏比例|目标股债占比|实际股债占比|备注（估值/操作记录）|
| ---- | ---- | ---- | ---- | ---- | ---- | ---- | ---- | ---- | ---- | ---- |
|示例|宽基指数|沪深300联接A|560|560|528|-32|-5.71%|20%|19%|PE分位42%，正常定投|
|示例|纯债基金|XX纯债|1960|2520|2530|10|0.40%|70%|72%|无操作|
|示例|货币基金|XX货基|280|280|280|0|0.00%|10%|9%|备用弹药|

### 配套公式（Excel里输入）
假设：
- D列：当月投入
- E列：累计总投入（E2=E1+D2，下拉填充）
- F列：当前市值（手动从基金APP抄）
- G列：持仓盈亏 = F2 - E2
- H列：盈亏比例 = IF(E2=0,0,G2/E2) → 设置单元格为百分比格式
- I列：目标占比（手动填固定值，如20%）
- J列：实际占比 = F2 / 【组合总市值（所有标的市值求和）】
